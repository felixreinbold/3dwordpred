Ein Just For Fun Projekt zum lernen.

Ein Programm welches eine Menge an Wörter nach ihren Eigenschaften in Dimensionen einordnet.
Nach dieser Einordnung wird in der Main Methode Eingaben (Falsch geschriebene Wörter zum Beispiel) aufgefordert,
welche dann ebenfalls wieder auf Basis der Dimensionen dem korrekten Wort zuordnen sollen. 

Quasi eine extrem schlechte Autokorrektur
